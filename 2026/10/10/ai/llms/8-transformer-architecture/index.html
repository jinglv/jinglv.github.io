Transformer 架构：LLM 如何理解 Token 之间的关系？

从 Token Embedding 出发，理解 Self-Attention、QKV、Causal Mask、Multi-Head Attention、残差连接、归一化和 FFN 如何组成现代 Decoder-only LLM。

Transformer 架构：LLM 如何理解 Token 之间的关系？

在前面的文章中，我们已经了解：

  • Tokenizer 把文本转换成 Token ID；
  • Chat Template 把对话组织成模型约定的输入格式；
  • 上下文窗口限制模型一次能够处理多少 Token；
  • Transformer 最终输出 Logits，用来预测下一个 Token；
  • KV Cache 保存历史 Token 的 Key 和 Value，加速逐 Token 生成。

但中间还缺少最重要的一块：

Token ID 进入模型后，究竟经历了什么，模型又是怎样结合上下文理解每个 Token 的？

这个问题的答案就是 Transformer。

Transformer 的核心价值不是简单记住单词，而是让序列中的每个位置根据其他相关位置动态计算自己的表示。

Transformer 出现之前

早期序列模型经常使用 RNN、LSTM 或 GRU，按照顺序逐步处理 Token：

这种结构能够处理序列，但训练时存在一些限制：

  • 时间步之间依赖较强，不容易充分并行；
  • 很长距离的信息需要经过多步传递；
  • 长序列上的梯度和记忆较难处理；
  • 训练大规模模型的效率受到限制。

2017 年的论文《Attention Is All You Need》提出 Transformer，使用 Attention 为主的结构替代循环结构。训练时，同一层中的多个 Token 可以并行计算，这为扩大数据、参数和计算规模提供了重要基础。

需要注意，论文标题虽然叫“Attention Is All You Need”，但完整 Transformer 并不只有 Attention。它还包括：

  • Embedding；
  • 位置信息；
  • Feed Forward Network；
  • Residual Connection；
  • Normalization；
  • 输出层。

Self-Attention 是什么？

Self-Attention 让序列中的每个位置，根据当前任务动态关注同一序列中的其他相关位置。

考虑句子：

当模型处理“她”时，需要结合上下文判断“她”更可能指向“小红”。Attention 提供了一种可学习的关系计算方式。

“Self”表示 Query、Key 和 Value 都来自同一个输入序列，而不是来自另一个编码器或外部数据库。

Residual Connection 有什么作用？

Residual Connection，也叫残差连接或跳跃连接，会把子层输入直接加回输出：

它的作用包括：

  • 保留原始信息通道；
  • 让子层主要学习需要补充的变化；
  • 改善深层网络的梯度传播；
  • 使大量 Transformer Block 可以稳定堆叠。

不能把 Residual 理解为简单“复制一份文本”。它传递的是 Hidden State 张量。

LayerNorm 与 RMSNorm

深层神经网络中的数值分布会不断变化。Normalization 用来稳定各层输入尺度，改善训练过程。

LayerNorm

LayerNorm 会进行均值中心化和方差缩放，再应用可学习参数。

RMSNorm

RMSNorm 主要根据均方根缩放向量，不做与 LayerNorm 完全相同的均值中心化。许多现代 LLM 使用 RMSNorm，因为它结构更简单、计算高效，并且在实践中表现良好。

为什么现代文本 LLM 常用 Decoder-only？

原始 Transformer 为机器翻译设计，包含 Encoder 和 Decoder。后来形成了三种常见架构。

Encoder-only

代表模型：BERT 类模型。

它适合理解输入，但默认不是按顺序生成长文本的架构。

Decoder-only

代表模型：GPT、Llama、Qwen 等大量生成式 LLM。

它把各种任务统一为文本续写：问答、翻译、摘要、代码生成都可以表示成“根据当前上下文继续生成”。

Encoder-Decoder

代表模型：原始 Transformer、T5 等。

它适合输入到输出的转换任务，例如翻译和摘要。

架构 Attention 特点 常见用途
Encoder-only 通常双向读取输入 分类、检索、Embedding、抽取
Decoder-only Causal，只看当前及以前 对话、文本生成、代码生成
Encoder-Decoder Encoder 双向，Decoder 因果并带 Cross-Attention 翻译、摘要、条件生成

Attention 权重能解释模型吗？

Attention Weights 可以帮助观察某一层、某个 Head 在一次计算中如何分配权重，但不能直接等同于模型完整的推理解释。

原因包括：

  • 模型有很多层和很多 Head；
  • Value 和输出投影会继续变换信息；
  • FFN 保存和处理大量特征；
  • Residual 会混合多条信息路径；
  • 相同输出可能由多个内部路径共同形成；
  • 最高 Attention 权重不等于对最终 Logit 的最大因果贡献。

因此，可视化 Attention 是分析工具之一，而不是“模型为什么这样回答”的完整证明。

Transformer 的知识存在哪里？

不能简单回答“都存在 Attention 里”。模型能力分布在：

  • Token Embedding；
  • Q/K/V/O 投影；
  • FFN / MLP 参数；
  • Normalization 参数；
  • LM Head；
  • 多层组件之间的组合关系。

研究通常认为 FFN 与事实和特征表示有密切关系，但知识不是一个可以直接读取的普通数据库表。模型回答问题时，会通过多层 Attention 与 MLP 的共同计算激活相关表示。

常见误区

误区一：Transformer 就是 Attention

Attention 是核心组件，但完整 Transformer 还包括 Embedding、位置信息、FFN、Residual、Normalization 和输出映射。

误区二：Attention 是在搜索模型训练数据

Self-Attention 处理的是当前序列中的 Hidden States，不会自动搜索原始训练语料或互联网。

误区三：Attention Weight 就是概率正确率

它表示某个 Head 在特定层中的信息聚合权重，不是事实正确概率。

误区四：每个 Attention Head 都有固定的人类可读职责

Head 的功能通过训练形成，可能分布、重叠或依赖其他层，不能机械标记成“语法 Head”“事实 Head”。

误区五：Decoder-only 模型看不到 Prompt

它不能看未来 Token，但可以通过 Causal Attention 读取当前位置之前的 System、历史消息、用户问题和已生成内容。

误区六：训练时模型逐 Token 串行计算所有位置

训练中已知完整序列，可以利用 Causal Mask 并行计算多个位置。推理时未来 Token 未知，才必须逐步生成。

误区七：位置编码只是给 Token 编号

位置机制会进入 Attention 关系计算。RoPE 等方法还会显式影响 Query 与 Key 的相对位置关系。

误区八：层数越多，模型一定越好

模型能力还取决于隐藏维度、数据、训练方法、参数分配、计算预算和优化稳定性。单独增加层数不保证质量提升。

误区九：KV Cache 保存了完整 Hidden States

标准 KV Cache 主要保存每一层历史位置的 Key 和 Value，不等同于保存全部中间状态。

误区十：FlashAttention 改变了模型含义

在等价配置和允许的数值误差下，FlashAttention 主要优化 Attention 的计算与内存访问方式，不是把模型换成另一套语义规则。

如何阅读一个真实 LLM 架构？

拿到模型配置时，可以按下面顺序检查：

  1. vocab_size：词表有多大；
  2. hidden_size：每个 Token 的主表示维度；
  3. num_hidden_layers：堆叠多少个 Block；
  4. num_attention_heads：Query Head 数；
  5. num_key_value_heads：是 MHA、GQA 还是 MQA；
  6. head_dim：每个 Head 的维度；
  7. intermediate_size：MLP 扩展维度；
  8. hidden_act：MLP 激活函数；
  9. max_position_embeddings 与 RoPE 配置：位置与上下文设置；
  10. Norm 类型和位置：Pre-Norm、Post-Norm、RMSNorm 或 LayerNorm；
  11. 是否使用 Sliding Window、MoE 等特殊结构；
  12. LM Head 是否与输入 Embedding 共享权重。

这些配置可以帮助我们判断参数主要花在哪里、KV Cache 大小如何估算，以及模型推理时可能有哪些性能特点。

小结

本文的核心内容可以总结为：

  1. Transformer 让每个 Token 根据上下文动态更新自己的 Hidden State；
  2. Token Embedding 提供初始表示，位置信息提供顺序和相对距离；
  3. Self-Attention 的 Q、K、V 来自同一序列；
  4. QKᵀ 计算匹配分数，Softmax 产生权重，再对 V 加权聚合；
  5. Causal Mask 保证当前位置不能看到未来 Token；
  6. Multi-Head Attention 允许模型在多个表示子空间中建模关系；
  7. MQA 和 GQA 通过减少 KV Head 降低 KV Cache 与推理带宽；
  8. FFN 对每个位置进行非线性特征变换；
  9. Residual 和 Normalization 让深层网络更容易稳定训练；
  10. 多个 Block 堆叠后，LM Head 将最终 Hidden States 映射成词表 Logits；
  11. Decoder-only、Encoder-only 和 Encoder-Decoder 适合不同任务；
  12. KV Cache 本质上缓存的是各层 Causal Self-Attention 的历史 Key 和 Value。
